# Project Retrospective

This document reflects on the portfolio project after development.

## What went well
The site pages are visually consistent and serve as a place for me to display my work. It also includes interactive hover effects and an About page, as the instructions requested.

## What I learned
Website development is an important and enjoyable skill to learn. Project 03 strengthened my understanding of HTML structure, shared CSS styling, navigation between pages, and organizing a website project for GitHub Pages. It was also the first time in a while I had tried to create a portfolio, so this assignment was a great way for me to revisit the trajectory of my career.

## What I would improve
In the future, I hope to have pages for my future projects and use imagery on my website to make it more visually appealing. In addition, I’d like to include more information on each item in my “Completed Work” section.
