# Laila's Portfolio Website
## Purpose:
The purpose of my portfolio website is to create a space where I can display my
previous work, creative projects, and house future ideas as I bring them to life.
The website will allow me to practice and demonstrate my skills in HTML, CSS,
Markdown, website organization, navigation, and responsive web design while helping
me not forget future goals I want to reach.
## Description:
My portfolio website will share information about me and organize my work and
creative interests into several sections. In addition to my previous work in
digital marketing, the website will include six additional topics:
- **Without Saying:** A future newspaper focused on being blunt about cultural
movements, fashion, and the complexity of humanity.
- **LAISCI:** A future smart fashion brand that combines fashion, technology, and
innovation.
- **Stories:** A collection of my creative writing projects and stories.
- **Lalivia:** A future fashion house and creative brand.
- **Charity Projects:** A section highlighting charitable ideas, community
projects, and work intended to create a positive impact.
- **Love, Laila:** A public journal to share personal reflections, ideas, and
observations.
## Desired Results:
I hope my portfolio website looks and functions like it was created by someone with
a strong understanding of HTML and CSS. I want the website to be visually
appealing, easy to navigate, and organized in a way that allows visitors to
understand the different areas of my work.
I also hope the website demonstrates my ability to create a multi-page website with
consistent navigation, responsive layouts, creative styling, and clear
organization.
## Exclusions:
This project does not include:
- Fully developing the businesses or organizations described on the website.
- Creating a functional online newspaper for Without Saying.
- Manufacturing or selling products for LAISCI or Lalivia.
- Creating a fully functional public blogging or publishing platform for Love,
Laila.
- Developing complex databases, user accounts, or payment systems.
- Creating mobile applications for any of the projects.
- Discussing the challenges or future business plans of these projects in detail.
## Resources:
- I plan to use Visual Studio Code to create and edit HTML and CSS files.
- I plan to use Markdown when appropriate for documenting my project.
- I expect to use GitHub to manage and publish my website.
- I will use a web browser to test the website during development.
- I may use Canva and other creative tools to prepare visual content for the
website.
## Priorities:
- Completing the website before the final project deadline.
- Demonstrating what I have learned about HTML, CSS, Markdown, and responsive web
design.
- Creating clear and functional navigation between pages.
- Making the website visually appealing and consistent.
- Organizing my previous digital marketing work and creative projects in a way that
is easy to understand.
- Creating a website structure that could be expanded in the future.
- Making sure the website works correctly on different screen sizes.
## Acceptance Criteria:
The project will be considered complete when:
- The website contains a functional homepage.
- The website includes navigation links that connect the major sections of the
site.
- The website includes a section for my previous work in digital marketing.
- The website includes sections for Without Saying, LAISCI, Stories, Lalivia,
Charity Projects, and Love, Laila.
- All navigation links work correctly.
- The website uses HTML and CSS appropriately.
- The website includes responsive design elements.
- The website has a consistent visual style, including colors, typography, spacing,
and layout.
- The website is tested in a web browser at different screen sizes.
- The website is published through GitHub.
- The final website meets the requirements established for the CMPA 3301 Final Project.
