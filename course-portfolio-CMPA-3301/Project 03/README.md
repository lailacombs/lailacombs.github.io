# Laila Combs Portfolio Website

## Project Purpose

This project is a personal portfolio website created as my final web design project. Its purpose is to introduce me, present my previous digital marketing and communication work, and create a home for the creative and entrepreneurial projects I plan to develop in the future.

The portfolio currently includes a **Home** page and an **About** page. The site uses a consistent visual style across both pages: elegant serif typography, a soft color palette, responsive layouts, and simple interactive effects.

The larger portfolio vision includes:
- Previous digital marketing work
- **Without Saying** — a future publication
- **LAISCI** — a future smart fashion project
- **Stories** — creative writing and storytelling
- **Lalivia** — a future fashion house
- **Charity Projects**
- **Love, Laila** — a public journal
